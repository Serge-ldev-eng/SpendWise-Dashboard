# SpendWise Dashboard - Personal Expense Tracker

## Overview
SpendWise is a personal expense tracker dashboard built for Week 4 assignment. It rebuilds the tracker's layout using modern CSS techniques.

## Layout Structure (Check 1)
- **Sidebar/Navigation:** Brand logo, 5 navigation items (Dashboard, Transactions, Analytics, Budgets, Settings), user profile
- **Header:** Dashboard title, subtitle, search box, Add Expense button
- **Cards Section:** 6 category cards (Food, Transport, Rent, Entertainment, Savings, Utilities) each with icon, amount, transaction count, and progress bar

## Technologies Used (Check 2 - Grid & Flexbox)
- **CSS Grid:** Main dashboard layout (`grid-template-areas`) and cards grid (`repeat(3, 1fr)`)
- **Flexbox:** Sidebar (`flex-direction: column`), header, card headers, navigation - all flex-based
- **No absolute positioning:** All layout done with Grid and Flexbox as required
